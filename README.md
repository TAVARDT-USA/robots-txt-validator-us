## Robots.txt Audit Capabilities

* **Indexation Trap Elimination**: Prevents disastrous de-indexing caused by misapplied root disallow directives.
* **Granular Bot Governance**: Segregates crawling permissions between search indexers and AI data collectors.
* **Sitemap Linkage Verification**: Audits the validity, accessibility, and declaration syntax of all sitemap references.
* **Directive Syntax Governance**: Probes pattern matching, parameter validity, and crawl delays.
* **Crawl Health Benchmark**: Standardised 0 to 100 rating with precise technical remediation protocols.

## Installation and Execution

Requires Python 3.8 or higher with zero external packages.

```bash
git clone https://github.com/TAVARDT-USA/robots-txt-validator-us.git
cd robots-txt-validator-us
python robots_validator.py https://example.com
```

For programmatic evaluation in JSON format:

```bash
python robots_validator.py https://example.com -json
```
